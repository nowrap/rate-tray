The colour is the interface

Three rules, and nothing else to learn

Watch the second number above climb past 75. Below the warning threshold a value carries its service's colour, shaded apart from the other limits of that service. Above it, severity takes over for everything — so a warning never depends on knowing which colour belongs to which service.

Colour is the second channel, never the only one: the percentage is always on the icon, the hover card names the limit, and both thresholds are yours to move.

Where the numbers come from

Read from the services, not guessed

Claude The OAuth usage endpoint, using the token Claude Code already keeps on disk.
Codex codex app-server over JSON-RPC, on the machine, no network call of our own.

Which limits exist depends on your plan, so the icon set is discovered from your account on first run rather than hardcoded. A failed poll keeps the last numbers on screen and backs off instead of blanking the tray.

Settings

Everything adjustable, nothing required

Right-click → Open settings. The colours tab previews the actual tray icons as you change them, derived palette included.

Install

One file, no installer

Download RateTray.exe and run it. Every release ships a SHA-256 checksum next to the binary.

What it touches

Two files read, one address by default

Credentials are read from the files the official CLIs already maintain, and are never copied, logged, or sent anywhere else. As shipped there is one destination — Anthropic's usage endpoint — and Codex data never leaves your machine at all. No telemetry, no update check.

That address is a setting rather than a constant, so that an endpoint which moves can be corrected without a new build. Which is why a credential only ever travels over https, and an endpoint other than the default is named in the app: changing where the numbers come from stays a visible choice.

You should not take any of that on trust. This reads your credential files, and it was written by an AI coding agent under human direction with no independent human review — a combination worth being sceptical about. Which is the useful thing about 352 KB and 3,350 lines of C#: it is small enough to read yourself before you run it.

The idea is lifted from Core Temp, which has been showing per-core CPU temperatures as numbers in the notification area for years. CodexBar on macOS and Win-CodexBar on Windows are the deluxe version of this idea — dozens of providers, dashboards, installers. If that is what you want, take one of those. RateTray keeps the Core Temp approach: the value is drawn into the icon, so there is nothing to open. It began as a spontaneous experiment, and both of those turned up later, while looking into what a macOS or Linux port would take.
